# Práctica: Comandos Básicos de Linux (Terminal)

## Objetivo
Practicar el uso de comandos básicos de navegación y listado de archivos y directorios en la terminal de Linux (Bash).

## Comandos utilizados

### `ls`
Lista el contenido del directorio actual.

### `ls -l`
Lista el contenido en formato largo, mostrando permisos, propietario, grupo, tamaño y fecha de modificación de cada archivo o carpeta.

### `ls -la`
Igual que `ls -l`, pero incluye también los archivos y carpetas ocultos (aquellos que empiezan con un punto `.`), como `.bashrc`, `.bash_history`, `.config`, etc.

### `ls -lh`
Muestra el listado en formato largo, pero con los tamaños de archivo en formato legible para humanos (KB, MB, GB) en lugar de bytes.

### `cd Documentos`
Cambia el directorio actual a la carpeta `Documentos`.

### `cd ..`
Regresa al directorio anterior (un nivel arriba).

### `cd ~`
Regresa directamente al directorio home del usuario.

## Resultado
Se navegó correctamente entre carpetas y se identificaron las diferencias entre los distintos formatos de listado (`ls`, `ls -l`, `ls -la`, `ls -lh`), observando permisos, propietarios, tamaños y archivos ocultos del sistema.
